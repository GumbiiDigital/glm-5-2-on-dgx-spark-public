# Serving operations record

The source includes the v2.0 manual, runbooks for two-system, three-system, four-system, sidecar, and larger serving shapes, a test matrix, validation guide, environment/inventory examples, RouterOS/systemd templates, and shell checks for preflight, model download, API smoke, benchmarking, and model-directory verification.

The operating conclusion is dry-run first: templates are reviewed and copied by an operator; they do not apply changes automatically. A current run requires fresh per-node evidence before it can be labeled verified.

Live inventory, model cache paths, credentials, endpoint addresses, and operational status are omitted from this public record.
